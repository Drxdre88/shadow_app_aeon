# Aeon — 20 Ultimate Strategic Directions (2026)

## I. AI-Native Project Management

1. **Autonomous AI Project Manager** — AI breaks goals into epics/tasks/dependencies via MCP `setup_board`
2. **Velocity-Aware Sprint Planning** — Auto-detect overcommitment using historical velocity data
3. **Multi-Agent Collaboration Board** — Humans + AI agents as assignees, agents auto-execute tasks
4. **Natural Language Board Control** — "Move all overdue high-priority tasks to top of In Progress"
5. **AI ↔ GitHub Sync** — PR opens → review task created, PR merged → card auto-completed + vaulted

## II. Real-Time & Multiplayer

6. **CRDT Real-Time Collaboration** — Yjs/Automerge for conflict-free multiplayer editing + offline-first
7. **Live Cursors & Presence** — Figma-style presence on the glassmorphism board
8. **Multiplayer Planning Poker** — Built-in estimation → feeds velocity calculations

## III. Spatial & Beyond-Screen

9. **Spatial Computing Board** — visionOS/Vision Pro: 3D glass panels, hand gesture dependency drawing
10. **Voice-First Task Management** — Whisper transcription → MCP tool execution
11. **AR Board Overlay** — Phone camera overlays digital board on physical whiteboard

## IV. Intelligence & Analytics

12. **Predictive Project Health Score** — Risk flags from velocity, dependencies, and task aging
13. **AI Forecasting with Monte Carlo** — "70% chance this ships by March 28" cone on Gantt
14. **Work Pattern Intelligence** — "Tasks with checklists complete 2x faster" actionable insights

## V. Platform & Ecosystem

15. **Plugin Marketplace** — Third-party integrations via MCP tools as plugin API
16. **Embeddable Board Widget** — `<AeonBoard>` component for any webpage/dashboard
17. **Developer CLI** — `aeon task add "Fix bug" --priority high` from the terminal

## VI. UX Innovation

18. **Cinematic View Transitions** — Cards fly between Board → Gantt → Canvas with layoutId animations
19. **Soundtrack Mode** — Generative ambient music responding to workflow tempo
20. **Personal AI Standup** — Morning brief: yesterday's progress, today's focus, risk alerts
