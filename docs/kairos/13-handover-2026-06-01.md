## What was decided this session (locked, not up for re-debate)

1. **The cosmic view stays.** Add organising intelligence on top — gravity wells, tier filters, archetype orbs, reflection beacons, Dominion cortex orb, time scrubber.
2. **Three-layer memory model:** substrate (streamed: agentic / execution / ideas) → archetypes (Kairos-synthesised master nodes per Dominion) → Dominion cortex (living document, the agent's model of the Dominion).
3. **Reflections are a first-class signal** — owner-fired, MCP today / phone tomorrow, higher weight than activity-derived drift, can override drift flags. Worked example: the ML / short-term power case from this session is captured in `12-` §"Worked example".
4. **Chat is built AFTER the data shape is fixed** — original Phase 1 sequencing of "chat first" was rejected; we go A (shape) → B (synthesis + reflections) → C (chat + graph) → D (loops).
5. **Phase 2 = active agent** (dual feedback loops, autonomous workflow triggers). **Phase 3 = identity / board-of-directors.** Both named with explicit gates so we don't sleepwalk into autonomy.
6. **Bulk board import was 20% signal, 80% noise.** Surgical prune (block A3) keeps rollups + rich tasks, removes ~200 empty shells.
