## 8. Recommended Approach: Next.js App Router + PWA in 2026

### Package: serwist (@serwist/next)
- Install: `npm install serwist @serwist/next`
- Wraps next.config.ts with withSerwist()
- Generates sw.js at build time in /public
- Supports App Router and Edge runtime awareness

### Implementation steps (high level):
1. Generate PWA icons from aeon.png (192, 384, 512, maskable 512, apple 180)
   Place icons in /public/icons/
2. Create /public/manifest.json with name, short_name, display: standalone,
   theme_color, background_color, icons array
3. Create /src/app/sw.ts — service worker entry point with serwist defaultCache
4. Wrap next.config.ts with withSerwist({ swSrc: 'src/app/sw.ts' })
5. Update layout.tsx metadata: add manifest link, themeColor, appleWebApp
6. CRITICAL: Update CSP header in next.config.ts to add worker-src 'self'
7. Optionally: add offline fallback route at /src/app/offline/page.tsx

### CSP Fix Required:
Current: `default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval'; ...`
Required addition: `worker-src 'self'`
Without this, Chrome/Edge will block service worker installation.

### display: standalone behavior:
- Removes browser chrome (address bar, nav buttons)
- App launches in its own window
- Requires manifest.json with display: "standalone"
- Requires HTTPS (already assumed via HSTS header)
